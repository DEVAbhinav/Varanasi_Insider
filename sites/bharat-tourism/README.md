# bharat-tourism

Isolated Next.js app for Azure Static Web Apps deployment. Everything inside this folder is separate from the primary site.

## Commands
- `npm install`
- `npm run dev`
- `npm run build`
- `npm start`

Update the GitHub Actions workflow secret `AZURE_STATIC_WEB_APPS_API_TOKEN_BHARAT_TOURISM` with the token from the SWA resource for this site.
