# Varanasi Tempo Traveller Booking Guide (2025)

This **practical booking guide** reduces ambiguity: exact steps from initial intent to confirmed vehicle dispatch, including documentation, pricing logic, and risk mitigation. Use this consolidated **tempo traveller booking guide varanasi** checklist to standardize enquiry quality and verification.

> Principle: Remove hidden variables early → fewer disputes later.

## 1. Define Trip Scope (Internal Clarity Phase)
List: Dates, passenger count, circuit (single destination vs multi), expected km (rough), luggage / special gear (cushions, instruments), seating comfort priority.

## 2. Initial Enquiry
Provide structured message:
```
Group: 11 pax (incl. 3 seniors)
Route: Varanasi → Bodh Gaya (2D/1N)
Dates: 12–13 Nov
Vehicle Preference: 12 seater (open to Urbania quote)
Focus: Meditation + low-noise cabin
Add-ons: Cushion storage, chilled water crate
```

## 3. Quote Components (Transparent Breakdown)
| Component | Typical Format | Notes |
| --- | --- | --- |
| Km Rate | ₹24–27 (standard) / Urbania ₹34–35 | Confirm base variant |
| Minimum Km / Day | 250–300 (if multi-day) | Charged if actual < minimum |
| Driver Allowance | ₹500–700 per night | Night halt clarity |
| Tolls / Parking | Actual | Option: pre-fund float |
| State Tax (if crossing) | Actual | Long circuits only |
| GST (if applicable) | 5% | Ask if invoice required |

## 4. Quote Validation Checklist
- Written message (email / WhatsApp PDF) summarizing inclusions
- Vehicle photos (inside + outside) – confirm recent (avoid stock only)
- RC snapshot (last 4 digits match day-of dispatch)
- Driver name issuance window (usually 12–18 hrs prior)

## 5. Advance & Payment Flow
| Stage | What | Risk Control |
| --- | --- | --- |
| Advance (T0) | 20–30% | Use traceable method (UPI / bank) |
| Pre-Dispatch (T-12h) | Balance readiness | Obtain driver & vehicle confirmation |
| En Route | Tolls / parking float if needed | Keep receipts / photo logs |
| Completion | Final settlement (km reconciliation) | Joint odometer photo |

## 6. Cancellation & Modification Norms (Model Policy)
| Timing | Refund Expectation | Rationale |
| --- | --- | --- |
| >7 days | Full less admin (₹300–500) | Slot can be refilled |
| 3–7 days | 50–70% | Partial loss window |
| 48–72 hrs | 0–30% | Low rebooking probability |
| <24 hrs | Likely no refund | Vehicle blocked |

## 7. Fraud / Misrepresentation Red Flags
- Only verbal assurances—no written fare breakup.
- Pressure for 50%+ advance without justification.
- Refusal to share RC / no GST number when invoice requested.
- Sudden “vehicle changed” message day-of with downgrade.

## 8. Document & Verification Kit
| Item | Why |
| --- | --- |
| Written Quote PDF / screenshot | Clear contract anchor |
| Vehicle RC (partial) | Authenticity check |
| Driver License (sighting) | Operational legality |
| Payment Receipts | Audit trail |
| GST Invoice (if business claim) | Compliance |

## 9. Dispatch Day Protocol
- Reconfirm pickup time night before.
- Odometer + fuel level photo at start.
- Re-verify seating layout meets requirement (recline, spacing).
- Stow baggage systematically (heavier bottom tier).

## 10. On-Tour Controls
| Control | Action | Benefit |
| --- | --- | --- |
| Daily Km Log | Photo morning + evening | Transparent reconciliation |
| Expense Pouch | Separate toll & parking slips | Faster settlement |
| Mid-Circuit Feedback | Quick pulse with group | Early correction |
| Hydration Rotation | Assign 2 pax / day | Maintains energy |

## 11. Post-Trip Closure
- Final km reconciliation (start vs end)
- Outstanding tolls settled
- Feedback note (vehicle comfort, driver conduct)
- Archive docs (quote, invoice, receipts) for repeat efficiency

## 12. Trust & Safety Signals (What to Look For)
| Signal | Indicator |
| --- | --- |
| Consistent Branding | Same name across website, messages, invoice |
| Transparent Escalation Path | Secondary contact shared |
| Proactive Vehicle Substitution Policy | Written fallback clause |
| Driver Rotation Policy (long circuits) | Prevents fatigue |
