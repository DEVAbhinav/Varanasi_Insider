## कम्पोज़िशन टिप्स (night photography focus)
- **लीडिंग लाइन:** घाट सीढ़ियाँ → दीप पंक्तियाँ  
- **रिफ्लेक्शन फ्रेम:** पानी में सममिति; भ्रंश सुधार हेतु हल्का क्रॉप  
- **Foreground Interest:** जलता दीप + पीछे घाट बोक़े  
- **सीक्वेंस:** प्रज्वलन क्रम (3–5 फ़्रेम) ब्लॉग / रील्स हेतु  

## HDR / ब्रैकेटिंग
- 5-फ़्रेम: -2 / -1 / 0 / +1 / +2 EV (लैंप ब्लोआउट बचाव)  
- मर्ज बाद में → हाईलाइट रिकवरी + शोर नियंत्रण।  

## मोबाइल फ़ोटोग्राफ़ी (dev deepawali mobile photography)
| सेटिंग | मान |
|--------|-----|
| मोड | मैनुअल / प्रो |
| ISO | 400–1600 (सीलिंग) |
| शटर | 1/60 (हाथ), 1/4–1s (ट्राइपॉड) |
| EV | -0.3 (हाईलाइट प्रटेक्शन) |
| फ़ॉर्मैट | RAW (यदि उपलब्ध) |

**मोबाइल टिप्स:** डिजिटल ज़ूम नहीं; wide + क्रॉप पोस्ट। नाइट मोड = एक शॉट के बाद कूल डाउन (नो मोशन ब्लर)।

## Long Exposure / Tripod Tips
| लक्ष्य | शटर रेंज | नोट |
|-------|-----------|-----|
| बोट लाइट ट्रेल | 1–2s | ISO कम रखें (800) |
| भीड़ soft motion | 0.5–1s | स्थिर foreground दीप |
| पूर्ण पैनोरमा | मल्टी 1/30 stitched | हैंड + overlap 30% |

## आवश्यक शॉट लिस्ट
- सम्पूर्ण पैनोरमिक (ब्लू आवर)  
- क्लोज़ दीप *low angle*  
- नाव सिल्हूट + लैंप प्रतिबिंब  
- हाथ से दीप प्रज्वलन मैक्रो  
- आरती लैंप स्विंग ट्रेल (1/10–1/4s प्रयोग)  
- भीड़ ऊपरी स्तर से पैटर्न  
- विपरीत तट “before / after lighting” डिप्टिक  

## रंग प्रबंधन
- हाईलाइट clipping चेतावनी ON  
- लैंप व्हाइट ≈ 3000–3200K; ब्लू आवर आकाश ~5500K → कस्टम WB 3400K = संतुलित  
- Vibrance हल्का (+15) Saturation सीमित (<+8)  

## सुरक्षा (गियर)
- भीड़ = कड़ा स्ट्रैप + बैग सामने  
- नाव: लेंस बदलना सीमित; पहले से *primary mid zoom* लगाएँ  
- आर्द्रता / धूल – माइक्रोफाइबर + रॉकेट ब्लोअर  

## पोस्ट प्रोसेस (संक्षिप्त वर्कफ़्लो)
