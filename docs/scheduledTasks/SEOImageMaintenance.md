## Images

Reuse a relevant, suitable existing authentic photo before generating anything. Inspect its actual appearance, dimensions, availability and current use. A filename is not evidence of location, fleet ownership or exact passenger capacity.

If a suitable photo is unavailable, use the available image-generation tool and the imagegen skill. Generate at most one new master image per run with at most one corrective regeneration. Read content first and save the exact prompt and provenance. Art direction: hyperrealistic editorial travel photography, one clear subject tied to the search intent, natural Indian light, realistic materials, believable scale, thumbnail-readable composition and room for responsive cropping. Verify identifiable landmarks using reliable references. Avoid invented geography, impossible vehicle access, fabricated amenities, distorted anatomy or vehicles, excessive HDR, text overlays, prices, badges, watermarks and invented logos. Do not pass illustrative imagery off as an actual customer trip or an owned vehicle. If tools are unavailable or quality fails, save the prompt and defer the image; never install a placeholder URL.

Prefer a new master at least 1600 pixels wide and a representative crawlable image at least 1200 pixels wide. Do not upscale a poor photo just to pass a threshold. Existing smaller images can still be valid; report their limits accurately. Compress appropriately and use dimensions/aspect ratio and loading behavior suited to the existing renderer. Add concise localized alt text to visible images. Reuse one asset across genuine translations when appropriate.

Follow the existing local/Cloudinary delivery path. Inspect upload scripts before execution. Legacy upload scripts may contain embedded credentials or bulk overwrite behavior: do not print, copy or execute those credentials; use environment-based credentials and upload only the new, uniquely named asset without overwriting existing assets. Never bulk-upload the image directory or alter CDN permissions. If no authorized upload path works, use a deployable local public asset if supported, or defer.

Align representative image references across the visible content, supported featured-image field, Open Graph, Twitter and applicable JSON-LD. Use absolute metadata URLs and verify reachability. Do not add unused frontmatter fields. If a shared change is needed for hero rendering or `max-image-preview:large`, record it separately instead of modifying the shared component during this daily run. Never weaken existing indexing directives.
